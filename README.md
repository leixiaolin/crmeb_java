### 📖 项目介绍：

CRMEB开源商城系统Java版，是一款基于Apache-2.0协议发布的开源电商解决方案。代码全开源无加密，可免费商用，适合各类企业及开发者快速构建多端一体化商城。

#### 技术架构

系统采用Java + Vue + uni-app技术栈，基于SpringBoot框架构建，前后端分离架构设计清晰。借助uni-app的跨端能力，轻松实现小程序、公众号、H5、APP、PC端全覆盖，数据统一、业务同步，极大提升开发与维护效率。同时，系统代码规范清晰，注释详尽，二次开发十分方便。

#### 核心功能

管理功能全面
系统核心管理功能完善，包含商品管理（支持SKU、属性、分类、评价）、订单管理、用户管理、购物车、物流管理、财务统计、多种支付方式等。

#### 丰富的营销工具

10余种营销功能能充分满足日常需求，包括拼团、砍价、秒杀、优惠券、签到、积分、等级会员、余额充值、分销裂变、活动边框、氛围图等，可灵活设置活动规则。

#### 可视化页面DIY装修

系统支持页面DIY设计，内置21种组件可自由拖拽设置，无需编码即可快速搭建个性化页面。`<br>`
图片热区：在一张图片中，为不同位置添加不同的跳转链接。`<br>`
图片魔方：一个组件，6种布局样式可选，能灵活满足使用需求。`<br>`
导航跳转：不仅能跳转商城内部页面，也能根据具体的运营环境跳转小程序、H5等。`<br>`
每种组件都有多种样式可选，组件细节支持自由调整。`<br>`

#### 社区共建计划

我们致力于打造开发者友好生态，开放源码、持续更新功能模块，并欢迎开发者提交优化建议或贡献代码。通过共享技术成果，降低行业重复造轮子成本，推动开源电商系统的可持续发展。

CRMEB开源商城PHP：https://gitee.com/ZhongBangKeJi/CRMEB

系统代码全开源无加密，独立部署、二开方便，适用于企业新零售、分销、拼团、砍价，秒杀等各种业务需求。

### 系统优势

#### 成熟稳定的架构

后端：SpringBoot + SpringSecurity，前端：Vue + ElementUI（PC管理端）与uni-app（移动端），多端并行开发，结构清晰。

#### 规范的接口设计

提供规范的RESTful API与数据结构，接口复用率高，逻辑层次清晰，便于二次开发与系统集成。

#### 数据与统计

集成ECharts实现多维数据看板，支持订单、用户、资金等多维度统计分析，数据可导出，助力运营决策。

#### 高效开发支持

支持Vue表单拖拽生成，大幅减少前端重复工作，提升开发效率。

#### 精细权限控制

基于Spring Security实现角色权限控制，可精确到按钮级别，保障系统安全。

#### 高可用设计

内置Redis队列，有效削峰解耦，提升系统并发能力与稳定性。

### 项目启动与部署

#### 1. 环境准备

本项目后端使用 Java 8、Maven、MySQL、Redis，管理后台使用 Node.js、npm、Vue 2.x，移动端使用 uni-app/HBuilderX。

建议环境：

```bash
Java 1.8
Maven 3.6.x
MySQL 5.7+
Redis 5.x+
Node.js 14.x
npm 6.x
```

#### 2. 初始化数据库和基础配置

1. 创建数据库，默认库名为 `single_open`。
2. 导入初始化 SQL：`crmeb/sql/Crmeb_v1.4.sql`。
3. 启动 Redis，默认地址为 `127.0.0.1:6379`。
4. 按本地环境修改后端配置：
   - 管理端：`crmeb/crmeb-admin/src/main/resources/application.yml`
   - 移动端接口：`crmeb/crmeb-front/src/main/resources/application.yml`

默认配置示例：

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/single_open
    username: single_open
    password: 111111
  redis:
    host: 127.0.0.1
    port: 6379
    password: 111111
```

首次启动前请重点检查数据库账号、Redis 密码、`crmeb.imagePath` 图片上传目录。生产环境不要直接提交真实账号、密钥、证书等敏感配置。

#### 3. 后端本地启动

进入后端 Maven 根目录：

```bash
cd crmeb
```

打包全部模块：

```bash
./mvnw clean package
```

Windows PowerShell：

```powershell
.\mvnw.cmd clean package
```

启动管理端 API，默认端口 `8080`：

```bash
./mvnw -pl crmeb-admin -am -DskipTests install
./mvnw -pl crmeb-admin spring-boot:run
```

启动移动端/前台 API，默认端口 `8081`：

```bash
./mvnw -pl crmeb-front -am -DskipTests install
./mvnw -pl crmeb-front spring-boot:run
```

Windows PowerShell 可使用：

```powershell
.\mvnw.cmd -pl crmeb-admin -am -DskipTests install
.\mvnw.cmd -pl crmeb-admin spring-boot:run

.\mvnw.cmd -pl crmeb-front -am -DskipTests install
.\mvnw.cmd -pl crmeb-front spring-boot:run
```

#### 4. 管理后台本地启动

进入管理后台目录：

```bash
cd admin
npm install
npm run dev
```

默认开发端口为 `9527`，可在 `admin/vue.config.js` 中查看。接口地址配置在 `admin/.env.development` 的 `VUE_APP_BASE_API`，本地联调时通常配置为管理端 API 地址，例如：

```env
VUE_APP_BASE_API = 'http://127.0.0.1:8080'
```

#### 5. 移动端本地运行

移动端工程位于 `app/`，建议使用 HBuilderX 打开该目录运行或发行。

常见检查项：

1. 在 `app/manifest.json` 中检查应用基础配置。
2. 在 `app/pages.json` 中检查页面配置。
3. 在 `app/api/` 相关文件中检查接口域名是否指向前台 API，例如 `http://127.0.0.1:8081`。
4. 根据目标端选择 H5、微信公众号、小程序或 App 运行方式。

#### 6. 生产部署

后端生产打包：

```bash
cd crmeb
./mvnw clean package -DskipTests
```

Windows PowerShell：

```powershell
cd crmeb
.\mvnw.cmd clean package -DskipTests
```

打包完成后，常用部署包位置：

```text
crmeb/crmeb-admin/target/*.jar
crmeb/crmeb-front/target/*.jar
```

服务器启动示例：

```bash
java -jar crmeb-admin/target/*.jar
java -jar crmeb-front/target/*.jar
```

如使用 profile 配置，可通过启动参数指定：

```bash
java -jar crmeb-admin/target/*.jar --spring.profiles.active=prod
java -jar crmeb-front/target/*.jar --spring.profiles.active=prod
```

管理后台生产构建：

```bash
cd admin
npm install
npm run build:prod
```

构建产物默认输出到 `admin/dist/`。将 `dist/` 部署到 Nginx、Apache 或对象存储静态站点，并把接口代理到管理端 API。Nginx 示例：

```nginx
server {
    listen 80;
    server_name admin.example.com;

    root /data/www/crmeb-admin/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

移动端生产发布请使用 HBuilderX 的发行功能，根据目标端生成 H5、小程序或 App 包。H5 产物部署到静态服务器时，接口域名需要指向 `crmeb-front` 服务。

#### 7. 部署检查清单

1. MySQL、Redis 已启动，账号密码与应用配置一致。
2. 已导入 `crmeb/sql/Crmeb_v1.4.sql`。
3. 后端 `imagePath` 目录存在且应用进程有读写权限。
4. 管理后台 `VUE_APP_BASE_API` 指向管理端 API。
5. 移动端接口域名指向前台 API。
6. 生产环境关闭演示站点开关，按需调整 `demoSite`、Swagger 访问控制、日志目录和上传目录。
7. Nginx 反向代理、跨域、HTTPS 证书和防火墙端口配置完成。
